# dual-scope-expense-analytics-dashboard
A financial analytics project for tracking and analyzing personal and corporate expenses using Python, MySQL, and Excel dashboards.
Dual Scope Expense Analytics Dashboard

Project Overview

The Dual Scope Expense Analytics Dashboard is a Financial Data Analytics project designed to manage, organize, and analyze both personal and corporate expenses within a unified system. The main objective of this project is to simplify financial tracking, improve data accuracy, and generate meaningful insights through structured data management and visualization.

The project focuses on transforming raw financial records into organized datasets and meaningful summaries, helping users understand spending patterns across different expense categories.

Objectives

- To organize personal and corporate financial records in a structured format.
- To manage and validate expense data using SQL.
- To automate category-wise expense calculations.
- To create meaningful financial summaries and visual dashboards.
- To improve the accuracy and efficiency of expense analysis.

Tools & Technologies Used

- Python: Used for initial data handling, file processing, and debugging.
- Visual Studio Code: Used as the development environment for Python scripts.
- MySQL Workbench: Used for database creation, table management, data organization, and SQL queries.
- Microsoft Excel: Used for data management, automated calculations, summary generation, and dashboard visualization.

Project Implementation

1. Data Preparation: Raw personal and corporate expense datasets were collected and prepared for analysis using Python and VS Code.

2. Database Management: Relational tables were created in MySQL Workbench to organize personal and corporate expense records systematically.

3. Data Import & Validation: Expense records were imported into MySQL tables, followed by SQL validation queries to check data accuracy and consistency.

4. Data Management in Excel: Cleaned datasets were transferred into Excel, where separate worksheets were maintained for personal and corporate expenses.

5. Expense Analysis: The SUMIF function was implemented to calculate category-wise expenses automatically for both personal and corporate records.

6. Dashboard Development: Column charts and summary sheets were created to present expense distribution and spending patterns visually.

Key Features

- Dual expense tracking for personal and corporate records.
- Structured database management using MySQL.
- Automated expense calculations using Excel formulas.
- Category-wise financial summaries.
- Visual representation through Excel charts.
- Organized and scalable financial data management.

Project Outcome

Successfully developed a Dual Scope Expense Analytics Dashboard that combines Python-based data handling, MySQL database management, and Excel-based financial analysis. The project provides an organized approach to tracking expenses, automating calculations, and visualizing financial information for better understanding and reporting.
